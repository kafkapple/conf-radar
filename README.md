# 학회 레이더 (conf-radar)

AI + 뇌과학/계산신경과학/NeuroAI + 국내(KSBNS) 학회의 **제출 마감·개최 일정**을 한 화면에서 본다.

- 웹 뷰어 = `docs/index.html` 파일 하나. 서버·빌드체인·런타임 의존성 없음.
- 모바일 = 같은 URL 을 아이폰 사파리에서 **공유 → 홈 화면에 추가**. `manifest.webmanifest` +
  `apple-touch-icon` 이 있어 전체화면 앱처럼 뜬다.
- 첫 화면 = **일정 타임라인**. 분기 / 6개월 / 1년 / 2년 창을 바꿔가며 잔여 일정을 본다.
- 뷰 6개: **일정 타임라인**(기본) · **목록**(D-day) · **칸반**(임박도 5열) · **표**(고밀도) · **지도** · **정보원**
- 정렬 7종: 마감 · 개최일 · 규모 · 티어 · CORE 등급 · 전형 주기 · 분야
- 등급 필터는 **하나짜리 라디오**다 — `메이저` · `T1·2` · `T1만` · `전체 티어` 중 하나.
  메이저를 별도 토글로 두면 티어와 AND 로 걸려서, T1·2 를 눌러도 메이저 5곳만 남는 화면이 된다
  (260910 사용자 신고로 수정). 빈 화면은 왜 비었는지와 무엇을 누르면 되는지를 같이 적는다.
- 그 밖의 필터: 그룹 · ★즐겨찾기(localStorage) · 워크샵 포함 · 제출 마감만 · 검색

## 단위 = 회차가 아니라 학회 시리즈

차기 회차가 아직 공지되지 않은 학회(ICML·ICCV·AISTATS 등)도 목록에 남는다.
과거 3-6년 회차에서 **전형 마감월·개최월**을 유도해 함께 보여준다.
표본 수(`n=`)를 항상 같이 찍으므로 약한 추정을 숨기지 않는다.

## 메이저 필터 — 분야 막론 최상위만

**메이저 = 독립된 두 외부 정본이 동시에 동의하는 6개.** CORE A\* 등급 **이면서** Google Scholar
h5-index 250 이상.

| 학회 | h5 | 분야 |
|---|---:|---|
| CVPR | 450 | 비전 |
| NeurIPS | 371 | ML |
| ICLR | 362 | ML |
| ICML | 272 | ML |
| ECCV | 262 | 비전 |
| ICCV | 256 | 비전 |

ECCV(짝수 해)와 ICCV(홀수 해)는 격년으로 번갈아 열린다. **한 해에 마감이 도는 것은 5곳**이다.

**손으로 뺀 학회는 없다.** 문턱 하나가 나머지를 가른다 — 특정 학회를 지목해 제외하기 시작하면
외부 정본이 아니라 취향이 된다. 아래는 전부 CORE A\* 지만 문턱 아래다.

`ACL 236` · `AAAI 232` · `EMNLP 218` · `IJCAI 136` · `ICRA 129` · `SIGGRAPH 114` · `RSS 83` · `COLT`

**왜 두 축인가** — 어느 한쪽만 쓰면 틀린다.

- CORE 등급만: 4단계뿐이라 A\* 안의 격차를 표현하지 못한다. COLT · RSS(83) · SIGGRAPH(114) ·
  ICRA(129) · IJCAI(136) 가 NeurIPS(371) 와 같은 칸에 들어간다.
- h5 만: 규모 편향이 등급 자리를 차지한다. 연 1회 대형 학회가 유리하고 격년제·소규모 학회가 불리하다.

**임계 250 의 근거** — 넓은 구간에서 같은 답을 준다. CORE A\* 중 h5 가 237~256 사이인 학회가
없어 임계를 237 로 내리든 256 으로 올리든 결과가 안 바뀐다. 바로 아래 경계는 ACL 236 이고
간격이 20 이다(2026-09-10 실측).

**5곳으로 더 줄일 수는 없다.** ECCV 262 와 ICCV 256 사이(간격 6)를 갈라야 하는데 둘은 격년으로
번갈아 열리는 같은 급이라 가를 근거가 없다.

**알려진 한계** (`data/impact.yml` 머리말에 같이 적어 뒀다)

- SIGGRAPH 는 본회의 논문이 ACM TOG 로 집계돼 Scholar 에 학회로 안 잡힌다(TOG h5 114).
  이 수치는 SIGGRAPH 를 과소평가한다.
- COLM(2024 창설)은 5년 창이 안 차 값이 없다. **값 없음은 낮음이 아니다.**
- 언어(ACL·EMNLP)는 이 컷에서 대표가 없다. 문턱을 237 아래로 내리는 대신 `T1` 티어나
  **분야별** 정렬로 본다.
- 뇌과학 학회에는 CORE 등급이 없어 이 필터에 잡히지 않는다. 뇌과학은 그룹 탭에서 본다.

**티어(`T1`)와 다른 점**이 정확히 이것이다. 티어에는 개인 축(내 연구와의 거리)이 섞여 있고
메이저에는 안 섞인다.

`build.py --check` 가 6곳 전원 포함 · ACL/AAAI/EMNLP/IJCAI/ICRA/SIGGRAPH/RSS/COLT 배제 · 총 6건을
assert 로 잡는다. 업스트림 등급 파싱이나 h5 표가 깨지면 필터가 조용히 틀리는 것을 막는다.

`https://kafkapple.github.io/conf-radar/#major` 로 열면 메이저 모드로 시작한다.

## 준비 착수선 — 언제부터 쓰기 시작할까

각 카드에 **`🛠 준비 착수 MM.DD (D-n)`** 한 줄이 붙는다. **마감 8주 전**이다.

- 고정 경험칙이고 학회가 공지하는 값이 아니다. 그래서 화면에도 그렇게 적어 둔다.
- 착수선이 이미 지난 학회는 `지금이 준비 기간` 으로 바뀐다.
- 마감순 정렬이 곧 착수순이다(상수를 뺀 것이라 순서가 같다). 정렬을 따로 두지 않았다.

## 리뷰 공개 수준 — 세 단계

투고처를 고를 때 트랙만큼 갈리는 축인데 어느 집계에도 없어서 `data/venues.yml` 에 직접 적는다.

| 표시 | 뜻 | 학회 |
|---|---|---|
| 🔓 전면공개 | 심사 중부터 논문·리뷰·저자 응답이 누구에게나 보이고, 탈락분도 영구 공개 | ICLR |
| ◐ 부분공개 | 결정 후 채택분만 공개. 심사 중에는 비공개 | NeurIPS · ICML |
| 🔒 비공개 | 리뷰가 공개되지 않는다. **OpenReview 를 써도 마찬가지** | CVPR · ACL(ARR) |

- 필터 바의 **🔓 공개 리뷰만** 이 전면공개만 남긴다. 검색창에서 `공개리뷰` 로도 걸러진다.
- CVPR 은 CVPR 2024부터 OpenReview 로 옮겼지만 리뷰는 비공개다. **플랫폼과 공개 여부는 다른 문제다.**
- arXiv 2510.13201 은 리뷰 점수의 초안-최종 변화를 공개하지 않는다는 이유로 ICML 을 closed 로 분류한다.
  우리는 "채택분 리뷰가 공개되는가"를 기준으로 삼아 partial 로 뒀고, 그 차이를 데이터 파일에 적어 뒀다.

## 발표 계층과 별도 트랙

"채택되면 어떤 등급으로 실리는가"와 "포지션·데이터셋 트랙이 따로 있는가"는 총 채택률만
봐서는 안 보인다. 업스트림 둘 다 이걸 안 나르므로 `data/venues.yml` 에 수동으로 기록한다.

| 학회 | 계층 | 최근 수치 | 별도 트랙 |
|---|---|---|---|
| CVPR | Oral · Highlight · Poster | 2025 13,008→2,878 (22.1%), 하이라이트 388 | 없음 |
| NeurIPS | Oral · Spotlight · Poster | 2025 21,575→5,290 (24.5%), 오랄 77 · 스포트라이트 683 | 평가·데이터셋(ED, 2021~) · 포지션(2025~) |
| ICLR | Oral · Spotlight · Poster | 2026 19,814→5,340 (27.0%), 스포트라이트 223 | 블로그(2022~) |
| ICML | Oral · Spotlight · Poster | 2025 12,107→3,260 (26.9%), 오랄 108 · 스포트라이트 313 | 포지션(2024~) |
| ACL | Oral · Poster (+ Findings) | 2025 8,360→1,699 (20.3%) | Findings(2020~) · 주제 트랙 · ARR 필수 |

- 카드·칸반에 아이콘 배지가 붙는다 — **📝 포지션**(실험 없이 관점만으로 낼 수 있는 트랙) ·
  **📊 벤치마크·데이터셋** · **📑 Findings**. 검색창에서 `포지션`, `Findings` 로도 걸러진다.
  나머지 트랙(블로그·주제·ARR)은 상세에서 본다.
- 배지가 없으면 **그 학회에 해당 트랙이 없다**는 뜻이다. 조사하지 않았다는 뜻이 아니다
  (`data/venues.yml` 에 `kind: none` 으로 명시한다).
- 상세 시트에 **발표 계층** 블록(연도별 계층 편수 + 출처)과 **별도 트랙** 블록(신설 연도 + 근거)이 있다.
- **NeurIPS 의 Datasets & Benchmarks 트랙은 2026년부터 Evaluations & Datasets (ED) 로 이름이 바뀌었다.**
- CVPR 은 계층이 **개최 2주 전쯤** 확정 공개된다. 채택 통보 때는 등급이 안 붙는다.
- ACL 은 본 학회 아래 **Findings** 라는 별도 게재 등급이 있어 "본 학회 채택률"과 "전체 게재율"이
  크게 다르다. 다른 넷과 한 줄에 놓고 비교하면 안 된다.

### 업스트림과 어긋난 값 (2026-09-10)

- **ICML 2024** — 업스트림은 채택 2,609, 우리 값 2,944. 2,609 는 papercopilot 의 **포스터 수와
  정확히 일치**한다. 업스트림이 오랄 144 · 스포트라이트 191 을 빠뜨린 것으로 보인다. 여기 값이 우선.
- **ACL 2024** — 업스트림 943 대 논문(arXiv 2512.04448) 865 → **943 으로 종결.**
  독립 집계 두 곳(csconfstats · openaccept.org)이 `4,407 / 943 / 21.40%` 로 일치한다.
  논문 쪽 계열은 "692 long-paper submissions" 로 시작하는 **long 전용 시계열**이라 865 는 long 만으로 읽힌다.
- **ACL 은 본 학회와 전체 게재가 크게 다르다** — 2025 본 학회 1,699(20.3%) 대 전체 게재 3,091(37.0%).
  다른 넷과 비교할 때는 본 학회 쪽을 쓴다.

수동 수치가 같은 해의 업스트림 값을 덮는다. 근거 URL 을 반드시 달고, 못 찾은 해는 비워 둔다.

## 타임라인 — 옆으로 스크롤해 내년까지

**연간 사이클 → 타임라인** 축이 기본 화면이다(`conf` 가 여기로 연다).

- 막대 하나 = 제출 마감 → 개최 종료. 왼쪽 세로선이 마감, 오른쪽 진한 조각이 개최 기간.
- **점선 빈 막대 = 과거 주기로 투영한 예상 마감월.** 공지된 날이 아니다. 라벨에 표본 수(`n=`)를 적는다.
  확정 마감과 45일 안쪽이면 같은 회차를 두 번 그리는 것이라 버린다.
- 6 / 12 / **24개월** 창. 24개월이면 내년 한 바퀴가 통째로 들어온다.
- 가로 스크롤 + 월 헤더 고정. 최소 폭 760px 라 폰에서도 스크롤로 본다.
- 창 안에 확정 일정도 예상도 없는 학회는 범례에 **이름과 전형 마감월로** 적는다. 조용히 사라지지 않는다.

## 설명은 화면에 두지 않는다

기준·근거 설명은 전부 **정보원 탭 → 기준과 한계** 한 곳에 모았다. 목록 화면에 두면 매번 읽어야
하는 벽이 되고, 벽은 읽히지 않는다. 본 화면에는 한 줄과 「기준과 한계 보기 →」 버튼만 둔다.

## 참고한 서비스

같은 문제를 푸는 서비스가 이미 있고, 겹치는 부분은 만들지 않고 가져다 쓴다.

| 서비스 | 우리가 쓰는 방식 |
|---|---|
| [ai-deadlines](https://huggingface.co/spaces/huggingface/ai-deadlines) | **업스트림.** 차기 마감을 빌드 때 자동으로 받아 온다 |
| [ccf-deadlines](https://ccfddl.com/) | **업스트림.** 회차 이력 · CORE 등급 · 투고/채택 수 |
| [Paper Copilot](https://papercopilot.com/statistics/) | 계층별 편수(오랄·스포트라이트·포스터)의 출처. 학회별 링크를 상세에 건다 |
| [Google Scholar Metrics](https://scholar.google.com/citations?view_op=top_venues&hl=en&vq=eng_artificialintelligence) | h5-index. 메이저 필터의 두 번째 축 |
| [CORE Portal](https://portal.core.edu.au/conf-ranks/) | 등급 원본 |
| [OpenReview](https://openreview.net/) | 학회별 검색 링크를 상세에 건다 |

이들이 공통으로 쓰는 관례 중 가져온 것 = **마감 시간대 표기**(카드에 원 표기 그대로),
**.ics 구독**, **분야 필터**. 안 가져온 것 = 초 단위 카운트다운(계획에는 D-day 로 충분하다).

이들에 없어서 우리가 만든 것 = **타임라인 예상 투영** · **준비 착수선** · **발표 계층·트랙 구분** ·
**뇌과학 학회 병합**(기계가독 피드가 존재하지 않는다).

## 지도 — 개최 빈도 heatmap

- **색 = 그 도시에서 열린 회차 수.** 1 / 2 / 3 / 4-5 / 6회+ 다섯 단계.
  구간은 고정값이다 — 데이터에 맞춰 자동으로 나누면 갱신될 때마다 같은 도시의 색이 바뀐다.
  회차 표본이 6년치라 실측 최댓값이 8(밴쿠버)이고, 그 분포에 맞춰 잘랐다.
- **원 크기**도 회차 수다(색과 같은 값을 두 번 부호화 — 작은 점의 색차가 안 보이기 때문).
- **테두리** = 뇌과학(실선) · 혼합(점선). 분야는 색을 빼앗기고 테두리로 갔다.
- **올해 개최지**는 바깥 링 + 라벨에 연도(`Vienna ’26`)를 붙여 강조하고, 도시 목록에서도 굵게 표시한다.
- 온라인 회차는 좌표가 없어 지도에 없다.

## 티어 기준

두 축의 조합이고, 객관 축은 우리가 정하지 않는다.

- **객관 축** = CORE 등급 (ccf-deadlines 가 실어 나르는 외부 정본). 신경과학 학회는 등급이
  부여되지 않아 분야 대표성으로 대신한다.
- **개인 축** = 연구 주제(3D 비전 · 행동/뇌 계측 · NeuroAI)와의 거리.
- **T1** = 둘 다 충족. **T2** = 한 축만. **T3** = 마감 캘린더용.
- 분야마다 T1 이 최소 하나 있는지 `build.py --check` 가 assert 로 강제한다.

## 데이터 출처 = 2계층

| 계층 | 대상 | 갱신 |
|---|---|---|
| 업스트림 | AI 학회 차기 마감 (`huggingface/ai-deadlines`) | 빌드 때 자동 fetch. **우리가 관리 안 함** |
| 업스트림 | 회차 이력 · CORE/CCF 등급 · 투고/채택 수 (`ccfddl/ccf-deadlines`) | 〃 |
| 자체 | 뇌과학 학회 `data/neuro.yml` | 수동. 뇌과학은 기계가독 피드가 존재하지 않음 |
| 자체 | 저널·학회 연계 제도 `data/programs.yml` | 수동. 확인한 것만 기록하고 미확인은 비워 둔다 |
| 자체 | 정보원 링크 `data/sources.yml` | 수동 |
| 자체 | h5-index `data/impact.yml` | 수동. 연 1회, Google Scholar 판이 바뀔 때 |

`data/neuro.yml` 의 각 마감에는 `status` 가 붙는다.

- `confirmed` — 학회가 공식 공지한 날짜
- `estimated` — 과거 패턴 기반 추정 (뷰어에 "추정" 표시)
- `tba` — 아직 미공지 (뷰어에 "미공지" 표시)

**추정·미공지 표시가 붙은 마감은 반드시 학회 사이트에서 재확인할 것.**

## 사용

셸에서는 `conf` 하나로 끝난다 (알리아스 정의는 `~/.zshrc`, 실체는 `scripts/conf.sh`).

```
conf            메이저 5곳 타임라인 (마감→개최 막대를 한 화면에)
conf list       메이저 5곳 목록 (D-day 순)
conf all        전체 38건 목록
conf web        공개 사이트 타임라인 (서버 안 씀)
conf update     업스트림 재수집 + 빌드 + 커밋·푸시
conf stop       로컬 서버 종료
conf status     서버 상태
```

**주소 끝 토큰으로 첫 화면이 정해진다.** `#major,cyc` = 메이저만 타임라인,
`#major,tbl` = 표, `#24m` = 24개월 창. 받는 토큰 = `major` · `list|kb|tbl|map|cyc|src` ·
`6m|12m|24m`, 구분자는 쉼표·`#`·`/`·`+` 아무거나.

로컬 서버를 쓰는 이유 = `file://` 에서는 서비스 워커가 등록되지 않아 오프라인 캐시가 죽는다.
서버를 끌 때 pid 파일만 본다 — `pkill -f` 는 그 명령 자신이 패턴에 걸린다.

### Alfred

`bash scripts/make_alfred_apps.sh` 를 한 번 돌리면 `~/Applications` 에 앱 두 개가 생긴다.

| Alfred 에서 | 하는 일 |
|---|---|
| `학회 레이더` | 서버 띄우고 메이저 타임라인 열기 |
| `학회 레이더 종료` | 서버 종료 |

「학회」 세 글자면 둘 다 뜬다. **Alfred 설정을 건드리지 않는다** — 워크플로·커스텀 검색은
plist 안에 들어가서 사람이 만들어야 하지만, Alfred 는 `~/Applications` 를 기본으로 훑기
때문에 앱 번들만 두면 잡힌다. GUI 로 뜨는 앱은 로그인 셸을 안 거쳐 `PATH` 가 최소라
번들 안에서 `PATH` 를 직접 세운다.

다른 경로 둘 — Alfred 에서 `>conf` (터미널 명령, 설정 불필요) · Web Search 커스텀 키워드로
`https://kafkapple.github.io/conf-radar/#major,cyc` 등록.

직접 돌릴 때:

```bash
uv run python build.py --check      # 업스트림 fetch + 병합 + docs/index.html 생성
uv run python build.py --offline    # 캐시된 업스트림으로 재빌드 (뷰어 수정 중일 때)
open docs/index.html
```

`sources.py` = 업스트림 읽기 전담, `build.py` = 합치기·유도·렌더. 갱신은 GitHub Actions 가
매일 05:00 KST 에 재빌드해 `main` 에 커밋하고 **`docs/` 를 `gh-pages` 로 배포**한다.

⚠️ Pages 소스가 `gh-pages` 브랜치이므로 `main` 커밋만으로는 공개 사이트가 안 바뀐다.
260910 이전 워크플로에는 배포 단계가 없어서 자동 재빌드가 공개본에 도달하지 못했다.

## 캘린더 연동

세 경로가 있고 쓰임이 다르다.

| 경로 | 어디서 | 성격 |
|---|---|---|
| **전체 구독** `deadlines.ics` | 정보원 탭 → "전체 구독 (webcal)" | 한 번 구독하면 매일 자동 갱신 |
| **학회 하나** | 학회 카드 → 상세 → "이 학회 일정 추가" | 그때 한 번, 그 학회만 |
| **즐겨찾기 / 현재 필터** | 정보원 탭 | 고른 것만 한 번 |

- 제출 마감은 종일 일정 + **마감 1주 전 알림**(VALARM), 개최 기간은 종일 일정.
- 추정·미공지 마감은 제목에 그대로 표기된다. 캘린더에 들어가도 확정값처럼 보이지 않게 한다.
- 아이폰은 `<a download>` 가 홈화면 앱 모드에서 잘 안 먹어 `data:` URL 로 넘긴다.

## 오프라인

`docs/sw.js` (서비스 워커). https 또는 localhost 에서만 등록되고, 실패해도 페이지는 정상 동작한다.

- **문서(HTML) = network-first** — 온라인이면 항상 최신, 끊기면 마지막 성공본.
  cache-first 로 하면 마감이 지난 낡은 페이지를 계속 보여주게 되어 이 도구에서는 위험하다.
- **정적 자산 = cache-first** — 아이콘·매니페스트는 거의 안 바뀐다.

## 홈화면 위젯

iOS 홈화면 위젯은 WidgetKit(네이티브 Swift)으로만 만들 수 있다. **PWA 는 위젯을 낼 수 없다.**
Xcode·개발자 계정·재서명을 피하려면 **Scriptable**(무료 앱)로 우회한다.

- 스크립트 = `widgets/conf-radar-widget.js` (설치 방법은 파일 상단 주석)
- 데이터는 사이트가 매일 갱신하는 `data.json` 을 그대로 읽는다. 위젯 쪽에 로직이 없다.
- 네트워크가 끊기면 마지막으로 받은 JSON 을 캐시에서 읽는다.

## 워크샵 추적

`data/workshops.yml`. 학회 부설 워크샵은 본 학회와 마감이 다르고 훨씬 빠듯해 따로 추적한다.

뷰어 안에서는 **학회와 같은 모양**으로 다룬다 (`kind: workshop` + `parent` 두 필드만 추가).
그래야 목록·칸반·표·타임라인·지도·캘린더가 전부 코드 변경 없이 워크샵도 처리한다.
별도 자료구조로 뒀다면 뷰 6개가 그것을 새로 배워야 했다.

- 카드·행에 `W · <본학회> 부설` 배지, 필터 바에 **워크샵 포함/제외** 토글.
- 후보 워크샵은 `data/sources.yml` → "워크샵" 그룹의 링크에서 고른다.
