# 학회 레이더 (conf-radar)

AI + 뇌과학/계산신경과학/NeuroAI + 국내(KSBNS) 학회의 **제출 마감·개최 일정**을 한 화면에서 본다.

- 웹 뷰어 = `docs/index.html` 파일 하나. 서버·빌드체인·런타임 의존성 없음.
- 모바일 = 같은 URL 을 아이폰 사파리에서 **공유 → 홈 화면에 추가**. `manifest.webmanifest` +
  `apple-touch-icon` 이 있어 전체화면 앱처럼 뜬다.
- 뷰 5개: **목록**(D-day) · **칸반**(임박도 5열) · **표**(고밀도) · **연간 사이클**(전형 주기 격자) · **정보원**
- 정렬 7종: 마감 · 개최일 · 규모 · 티어 · CORE 등급 · 전형 주기 · 분야
- 필터: 그룹 · 티어 · **메이저** · ★즐겨찾기(localStorage) · 제출 마감만 · 검색

## 단위 = 회차가 아니라 학회 시리즈

차기 회차가 아직 공지되지 않은 학회(ICML·ICCV·AISTATS 등)도 목록에 남는다.
과거 3-6년 회차에서 **전형 마감월·개최월**을 유도해 함께 보여준다.
표본 수(`n=`)를 항상 같이 찍으므로 약한 추정을 숨기지 않는다.

## 메이저 필터 — 분야 막론 최상위만

**메이저 = 독립된 두 외부 정본이 동시에 동의하는 6개.** CORE A\* 등급 **이면서** Google Scholar
h5-index 250 이상.

| 학회 | h5 | 분야 |
|---|---:|---|
| CVPR | 450 | 비전 |
| NeurIPS | 371 | ML |
| ICLR | 362 | ML |
| ICML | 272 | ML |
| ECCV | 262 | 비전 |
| ICCV | 256 | 비전 |

ECCV(짝수 해)와 ICCV(홀수 해)는 격년으로 번갈아 열린다. **한 해에 마감이 도는 것은 5곳**이다.

**손으로 뺀 학회는 없다.** 문턱 하나가 나머지를 가른다 — 특정 학회를 지목해 제외하기 시작하면
외부 정본이 아니라 취향이 된다. 아래는 전부 CORE A\* 지만 문턱 아래다.

`ACL 236` · `AAAI 232` · `EMNLP 218` · `IJCAI 136` · `ICRA 129` · `SIGGRAPH 114` · `RSS 83` · `COLT`

**왜 두 축인가** — 어느 한쪽만 쓰면 틀린다.

- CORE 등급만: 4단계뿐이라 A\* 안의 격차를 표현하지 못한다. COLT · RSS(83) · SIGGRAPH(114) ·
  ICRA(129) · IJCAI(136) 가 NeurIPS(371) 와 같은 칸에 들어간다.
- h5 만: 규모 편향이 등급 자리를 차지한다. 연 1회 대형 학회가 유리하고 격년제·소규모 학회가 불리하다.

**임계 250 의 근거** — 넓은 구간에서 같은 답을 준다. CORE A\* 중 h5 가 237~256 사이인 학회가
없어 임계를 237 로 내리든 256 으로 올리든 결과가 안 바뀐다. 바로 아래 경계는 ACL 236 이고
간격이 20 이다(2026-09-10 실측).

**5곳으로 더 줄일 수는 없다.** ECCV 262 와 ICCV 256 사이(간격 6)를 갈라야 하는데 둘은 격년으로
번갈아 열리는 같은 급이라 가를 근거가 없다.

**알려진 한계** (`data/impact.yml` 머리말에 같이 적어 뒀다)

- SIGGRAPH 는 본회의 논문이 ACM TOG 로 집계돼 Scholar 에 학회로 안 잡힌다(TOG h5 114).
  이 수치는 SIGGRAPH 를 과소평가한다.
- COLM(2024 창설)은 5년 창이 안 차 값이 없다. **값 없음은 낮음이 아니다.**
- 언어(ACL·EMNLP)는 이 컷에서 대표가 없다. 문턱을 237 아래로 내리는 대신 `T1` 티어나
  **분야별** 정렬로 본다.
- 뇌과학 학회에는 CORE 등급이 없어 이 필터에 잡히지 않는다. 뇌과학은 그룹 탭에서 본다.

**티어(`T1`)와 다른 점**이 정확히 이것이다. 티어에는 개인 축(내 연구와의 거리)이 섞여 있고
메이저에는 안 섞인다.

`build.py --check` 가 6곳 전원 포함 · ACL/AAAI/EMNLP/IJCAI/ICRA/SIGGRAPH/RSS/COLT 배제 · 총 6건을
assert 로 잡는다. 업스트림 등급 파싱이나 h5 표가 깨지면 필터가 조용히 틀리는 것을 막는다.

`https://kafkapple.github.io/conf-radar/#major` 로 열면 메이저 모드로 시작한다.

## 준비 착수선 — 언제부터 쓰기 시작할까

각 카드에 **`🛠 준비 착수 MM.DD (D-n)`** 한 줄이 붙는다. **마감 8주 전**이다.

- 고정 경험칙이고 학회가 공지하는 값이 아니다. 그래서 화면에도 그렇게 적어 둔다.
- 착수선이 이미 지난 학회는 `지금이 준비 기간` 으로 바뀐다.
- 마감순 정렬이 곧 착수순이다(상수를 뺀 것이라 순서가 같다). 정렬을 따로 두지 않았다.

## 티어 기준

두 축의 조합이고, 객관 축은 우리가 정하지 않는다.

- **객관 축** = CORE 등급 (ccf-deadlines 가 실어 나르는 외부 정본). 신경과학 학회는 등급이
  부여되지 않아 분야 대표성으로 대신한다.
- **개인 축** = 연구 주제(3D 비전 · 행동/뇌 계측 · NeuroAI)와의 거리.
- **T1** = 둘 다 충족. **T2** = 한 축만. **T3** = 마감 캘린더용.
- 분야마다 T1 이 최소 하나 있는지 `build.py --check` 가 assert 로 강제한다.

## 데이터 출처 = 2계층

| 계층 | 대상 | 갱신 |
|---|---|---|
| 업스트림 | AI 학회 차기 마감 (`huggingface/ai-deadlines`) | 빌드 때 자동 fetch. **우리가 관리 안 함** |
| 업스트림 | 회차 이력 · CORE/CCF 등급 · 투고/채택 수 (`ccfddl/ccf-deadlines`) | 〃 |
| 자체 | 뇌과학 학회 `data/neuro.yml` | 수동. 뇌과학은 기계가독 피드가 존재하지 않음 |
| 자체 | 저널·학회 연계 제도 `data/programs.yml` | 수동. 확인한 것만 기록하고 미확인은 비워 둔다 |
| 자체 | 정보원 링크 `data/sources.yml` | 수동 |
| 자체 | h5-index `data/impact.yml` | 수동. 연 1회, Google Scholar 판이 바뀔 때 |

`data/neuro.yml` 의 각 마감에는 `status` 가 붙는다.

- `confirmed` — 학회가 공식 공지한 날짜
- `estimated` — 과거 패턴 기반 추정 (뷰어에 "추정" 표시)
- `tba` — 아직 미공지 (뷰어에 "미공지" 표시)

**추정·미공지 표시가 붙은 마감은 반드시 학회 사이트에서 재확인할 것.**

## 사용

셸에서는 `conf` 하나로 끝난다 (알리아스 정의는 `~/.zshrc`, 실체는 `scripts/conf.sh`).

```
conf            메이저 학회만, 로컬 서버(:8897) 로 열기
conf all        전체 목록으로 열기
conf web        공개 사이트 열기 (서버 안 씀)
conf update     업스트림 재수집 + 빌드 + 커밋·푸시
conf stop       로컬 서버 종료
conf status     서버 상태
```

로컬 서버를 쓰는 이유 = `file://` 에서는 서비스 워커가 등록되지 않아 오프라인 캐시가 죽는다.
서버를 끌 때 pid 파일만 본다 — `pkill -f` 는 그 명령 자신이 패턴에 걸린다.

Alfred 는 키워드 하나를 사이트에 걸어 쓴다 (워크플로 plist 는 사람이 만든다).

- 셸 명령으로: Alfred 에서 `>conf` — 터미널이 열리며 알리아스가 그대로 돈다. 설정 불필요.
- 웹 검색으로: Alfred 환경설정 → Features → Web Search → Add Custom Search,
  URL `https://kafkapple.github.io/conf-radar/#major`, 키워드 `conf`.

직접 돌릴 때:

```bash
uv run python build.py --check      # 업스트림 fetch + 병합 + docs/index.html 생성
uv run python build.py --offline    # 캐시된 업스트림으로 재빌드 (뷰어 수정 중일 때)
open docs/index.html
```

`sources.py` = 업스트림 읽기 전담, `build.py` = 합치기·유도·렌더. 갱신은 GitHub Actions 가
매일 05:00 KST 에 재빌드해 `main` 에 커밋하고 **`docs/` 를 `gh-pages` 로 배포**한다.

⚠️ Pages 소스가 `gh-pages` 브랜치이므로 `main` 커밋만으로는 공개 사이트가 안 바뀐다.
260910 이전 워크플로에는 배포 단계가 없어서 자동 재빌드가 공개본에 도달하지 못했다.

## 캘린더 연동

세 경로가 있고 쓰임이 다르다.

| 경로 | 어디서 | 성격 |
|---|---|---|
| **전체 구독** `deadlines.ics` | 정보원 탭 → "전체 구독 (webcal)" | 한 번 구독하면 매일 자동 갱신 |
| **학회 하나** | 학회 카드 → 상세 → "이 학회 일정 추가" | 그때 한 번, 그 학회만 |
| **즐겨찾기 / 현재 필터** | 정보원 탭 | 고른 것만 한 번 |

- 제출 마감은 종일 일정 + **마감 1주 전 알림**(VALARM), 개최 기간은 종일 일정.
- 추정·미공지 마감은 제목에 그대로 표기된다. 캘린더에 들어가도 확정값처럼 보이지 않게 한다.
- 아이폰은 `<a download>` 가 홈화면 앱 모드에서 잘 안 먹어 `data:` URL 로 넘긴다.

## 오프라인

`docs/sw.js` (서비스 워커). https 또는 localhost 에서만 등록되고, 실패해도 페이지는 정상 동작한다.

- **문서(HTML) = network-first** — 온라인이면 항상 최신, 끊기면 마지막 성공본.
  cache-first 로 하면 마감이 지난 낡은 페이지를 계속 보여주게 되어 이 도구에서는 위험하다.
- **정적 자산 = cache-first** — 아이콘·매니페스트는 거의 안 바뀐다.

## 홈화면 위젯

iOS 홈화면 위젯은 WidgetKit(네이티브 Swift)으로만 만들 수 있다. **PWA 는 위젯을 낼 수 없다.**
Xcode·개발자 계정·재서명을 피하려면 **Scriptable**(무료 앱)로 우회한다.

- 스크립트 = `widgets/conf-radar-widget.js` (설치 방법은 파일 상단 주석)
- 데이터는 사이트가 매일 갱신하는 `data.json` 을 그대로 읽는다. 위젯 쪽에 로직이 없다.
- 네트워크가 끊기면 마지막으로 받은 JSON 을 캐시에서 읽는다.

## 워크샵 추적

`data/workshops.yml`. 학회 부설 워크샵은 본 학회와 마감이 다르고 훨씬 빠듯해 따로 추적한다.

뷰어 안에서는 **학회와 같은 모양**으로 다룬다 (`kind: workshop` + `parent` 두 필드만 추가).
그래야 목록·칸반·표·타임라인·지도·캘린더가 전부 코드 변경 없이 워크샵도 처리한다.
별도 자료구조로 뒀다면 뷰 6개가 그것을 새로 배워야 했다.

- 카드·행에 `W · <본학회> 부설` 배지, 필터 바에 **워크샵 포함/제외** 토글.
- 후보 워크샵은 `data/sources.yml` → "워크샵" 그룹의 링크에서 고른다.
